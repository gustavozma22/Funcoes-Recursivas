# Funcoes-Recursivas
1. RECURSIVIDADE E ESTRUTURAS ESTATICAS

1.1. Recursao Escalar na Pilha de Chamadas (Call Stack)
- Arquivo: ex2_potenciacao_recursiva.c
- Descricao: Calcula a potenciacao de um numero inteiro utilizando reducao sucessiva do expoente na pilha de execucao, sem uso de vetores ou estruturas auxiliares.

1.2. Vetores Unidimensionais (Arrays 1D)
- Arquivos:
  * ex1_soma_vetor_recursiva.c (Soma os elementos de um vetor alocado dinamicamente na stack)
  * ex3_busca_sequencial_recursiva.c (Realiza busca linear recursiva em um array estatico)
  * ex4_decimal_para_binario.c (Converte numero decimal para representacao binaria de 8 bits utilizando vetor fixo e impressao recursiva)
- Descricao: Manipulacao de dados contiguos na memoria utilizando percorrimento recursivo de indices.

1.3. Matrizes Bidimensionais e Backtracking
- Arquivo: ex5_labirinto_backtracking.c
- Descricao: Busca em profundidade utilizando recursao (backtracking) em uma matriz bidimensional de caracteres para encontrar um caminho entre um ponto inicial e final.
